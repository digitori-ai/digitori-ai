The philosophy

Built on S4 — Goal Driven Development

A code agent ships code. A product agent ships outcomes. Every Digitori run starts from a measurable product goal, flows through the SIV loop, and is only complete when verification proves the goal was met — not just that the code compiles.

🎯 One human gate

Goal approval is the only mandatory human decision. After that, autopilot resolves unknowns with logged assumptions — every decision lands in the run-log for review.

📏 Scale-adaptive depth

S for patches, M for features, L for systems — ceremony adjusts to the size of the change. But the Verify phase is never skipped. That is the point.

🛡️ Verified outcomes

A spec can be perfectly implemented and still fail the reason you wrote it. Digitori's verifier is adversarial: it proves the outcome happened, or the loop continues.
